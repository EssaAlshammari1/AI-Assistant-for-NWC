# NWC RAG Website

الواجهة الأمامية للمساعد الذكي لشركة المياه الوطنية (NWC) — مبنية بـ JavaScript و HTML و CSS، تتصل بواجهة RAG الخلفية على المنفذ `8000`.

## 1. تشغيل واجهة RAG

من مجلد المشروع الرئيسي:

```powershell
cd C:\Users\essa4\Desktop\projects\pdf
.\.venv\Scripts\python.exe pro2\api.py
```

يرد على:

- `GET /health` — للتحقق من الحالة.
- `POST /ask` — لطرح سؤال: `{"question": "..."}` ويرجع `{"answer": "...", "sources": [{"text": "...", "score": 0.0}]}`.

> أول سؤال قد يستغرق وقتًا أطول لأن النموذج يُحمَّل عند أول طلب. الأسئلة اللاحقة تعيد استخدامه.

## 2. تشغيل الموقع

افتح نافذة PowerShell أخرى:

```powershell
cd C:\Users\essa4\Desktop\projects\pdf
python -m http.server 5500
```

ثم افتح في المتصفح:

```text
http://127.0.0.1:5500/pro2/rag-website/
```

## 3. الشعار

ضع شعار الشركة في:

```text
assets/nwc logo.png
```

(المسار النسبي من مجلد `rag-website/` هو `../assets/nwc logo.png`). إذا لم يكن الملف موجودًا، يعرض الموقع علامة النص `NWC` كبديل.

## 4. مشاركة الموقع مع الآخرين

### على نفس شبكة Wi-Fi

اعرف عنوان IPv4 لجهازك باستخدام `ipconfig`، ثم شغّل API ليستمع على الشبكة:

```powershell
$env:RAG_HOST = "0.0.0.0"
.\.venv\Scripts\python.exe pro2\api.py
```

في نافذة أخرى شغّل الموقع كما في الخطوة السابقة، ثم شارك هذا العنوان بعد استبدال `192.168.1.20` بعنوان جهازك:

```text
http://192.168.1.20:5500/pro2/rag-website/?api=http://192.168.1.20:8000
```

قد تحتاج إلى السماح للمنفذين `5500` و`8000` في Windows Firewall.

### عبر الإنترنت للاختبار المؤقت

ثبّت `cloudflared` من Cloudflare، ثم اترك نافذة API ونافذة الموقع تعملان. افتح نافذتين إضافيتين:

```powershell
cloudflared tunnel --url http://127.0.0.1:8000
```

```powershell
cloudflared tunnel --url http://127.0.0.1:5500
```

سيطبع كل أمر رابطًا عامًا مؤقتًا. افتح رابط الموقع وأضف رابط API في آخره، مثل:

```text
https://your-site.trycloudflare.com/pro2/rag-website/?api=https://your-api.trycloudflare.com
```

شارك رابط الموقع النهائي فقط. هذه الروابط مؤقتة، وواجهة API لا تحتوي على تسجيل دخول، لذلك استخدمها للاختبار فقط وأوقف النوافذ بعد الانتهاء.
